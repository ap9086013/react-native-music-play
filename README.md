# react-native-music-play

A lightweight native music player for React Native witj play ,pause, seek, and progress events.

## Installation


```sh
npm install react-native-music-play
```


## Usage


```js
import { multiply } from 'react-native-music-play';

// ...

const result = multiply(3, 7);
```
